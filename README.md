# Laravel DDD Wiki

이 저장소는 Laravel + Domain-Driven Design(DDD) 지식을 체계적으로 축적하기 위한 LLM Wiki입니다. 책, PDF, 아티클, 공식 문서에서 얻은 지식을 정제해 Markdown 페이지로 저장하고, Obsidian과 GitHub 모두에서 쉽게 탐색할 수 있도록 구성했습니다.

## 이 저장소의 목적

이 프로젝트는 일반적인 애플리케이션 코드베이스가 아니라, 다음을 위한 지식 베이스입니다.

- Laravel로 실제 서비스를 설계할 때 사용할 수 있는 DDD 개념 정리
- 도메인 언어와 구현 패턴을 연결한 실전 지식 축적
- LLM 및 인간 모두가 재사용 가능한 형태로 참고할 수 있는 위키 구조 제공

## 핵심 구성

- sources/: 원본 문서와 자료를 보관하는 읽기 전용 디렉터리
- wiki/: 주제별로 정리된 지식 페이지들
- index.md: 카테고리별 페이지 인덱스
- schema.md: 위키 페이지 작성 규칙과 구조 정의
- log.md: 추가/갱신 이력 기록
- .claude/commands/: Claude Code에서 사용하는 인제스트, 질의, 린트 워크플로 명령 정의
- .claude/skills/: Claude Code가 위키 작업을 더 잘 수행하도록 돕는 재사용 가능한 스킬 집합

## Claude Code 스킬

이 저장소에는 Claude Code용 스킬이 포함되어 있으며, 주로 다음 작업을 지원합니다.

- ingest: 새 소스 문서를 읽고, 관련 위키 페이지를 생성하거나 갱신하는 병합 작업을 진행한다
- query: 저장된 위키 지식을 바탕으로 질문에 답변하고, 필요한 경우 새 지식을 정리한다
- lint: 위키의 링크, 메타데이터, 인덱스 일관성을 점검하고 필요한 수정을 수행한다

이 스킬은 다음과 같은 상황에서 쓰입니다.

- 새 Laravel/DDD 관련 자료를 위키에 추가하고 싶을 때
- 기존 위키 내용을 기반으로 질문에 답변하고 싶을 때
- 위키의 구조와 링크가 깨졌는지 점검하고 정리하고 싶을 때

## 주요 카테고리

- ddd-core: 엔티티, 값 객체, 애그리거트, 도메인 이벤트 등 DDD 핵심 개념
- laravel: Laravel와 DDD를 연결하는 구현 패턴과 실전 가이드
- architecture: 계층형 아키텍처, CQRS 등 아키텍처 패턴
- patterns: 리포지토리, 매퍼, 파이프라인, 유닛 오브 워크 등 구현 패턴
- testing: 도메인 테스트, 기능 테스트, TDD 전략
- tooling: 정적 분석, CI/CD, Laravel Boost 등 개발 도구
- frontend: Tailwind CSS 및 Laravel 프론트엔드 전략

## 어떻게 쓰는가

1. 저장소 루트의 index.md에서 주제별 페이지를 탐색합니다.
2. 관심 있는 개념이 있으면 wiki/ 아래 해당 페이지를 읽습니다.
3. 새로운 소스를 추가할 때는 sources/에 보관하고, 관련 위키 페이지를 확장합니다.
4. 페이지 작성 규칙은 schema.md를 참고합니다.

## 운영 원칙

- 패턴보다 도메인 언어를 먼저 다룹니다.
- 이론적 순수성보다 프로젝트 전체의 일관성을 우선합니다.
- 원본 자료는 수정하지 않고, 정제된 위키 형태로 보존합니다.

## 참고

이 위키는 Obsidian으로 편집하기 좋게 설계되었지만, GitHub에서도 그대로 탐색할 수 있습니다. 새로운 지식을 추가하거나 기존 내용을 보완하고 싶다면 위키 구조와 작성 규칙을 먼저 확인하는 것이 좋습니다.
