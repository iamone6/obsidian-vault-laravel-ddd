# Query

위키에서 질문에 대한 답을 찾아 종합한다. 관련 페이지를 읽고 연결된 개념을 추적하여 종합적인 답변을 생성한다.

## 사용법

```
/query <질문>
```

## 실행 절차

**1단계 — 질문 분석**

`$ARGUMENTS`를 질문으로 받아 핵심 키워드와 관련 DDD/Laravel 개념을 파악한다.

**2단계 — 관련 페이지 탐색**

- `index.md`를 읽어 관련 카테고리와 페이지를 파악한다
- 키워드와 관련된 `wiki/` 페이지들을 읽는다
- 페이지 내 `[[링크]]`를 따라 연결된 페이지도 확인한다
- `log.md`에서 관련 주제의 최근 변경 이력을 참고한다

**3단계 — 답변 종합**

읽은 페이지들의 내용을 바탕으로 질문에 답한다:
- 핵심 개념 설명
- Laravel 구현 방법 (코드 예제 포함)
- 주의사항 / 안티패턴
- 관련 페이지 링크 (`[[페이지명]]` 형식)

**4단계 — 위키 보완 (선택)**

답변 과정에서 다음을 발견하면 제안한다:
- 위키에 아직 없는 유의미한 개념 → 새 페이지 생성 여부 확인
- 기존 페이지에 보완할 내용 → 갱신 여부 확인
- 끊어진 `[[링크]]` → 수정 여부 확인

사용자가 동의하면 페이지를 생성/갱신하고 `log.md`에 기록한다:
```
[YYYY-MM-DD] [ADD] 질의 응답 중 PageName 페이지 생성
```
